# 星兽突围（StarBeasts）

原创 3D 浏览器幸存者游戏原型，灵感来自 Vampire Survivors 类玩法。角色、敌人与升级均为原创设定，不包含任何第三方 IP 素材。

## 技术栈

- Vite + TypeScript
- Three.js（WebGL 3D）
- Web Audio API（程序化音效 / BGM，无外部音频文件）
- 纯前端，无需后端


## 视觉 / 美术（Art Pass）

本轮为**原创低多边形**外观升级，不引入外部模型或第三方 IP 形象：

| 类别 | 变化 |
|------|------|
| 角色 | 焰心狐 / 潮汐龟 / 风刃隼：头身肢尾（或翼）多部件组合；呼吸缩放、尾摆 / 壳起伏 / 振翼 |
| 敌人 | 暗晶兽、裂影狼、虚空甲虫多部件；精英双层装甲 + 脚底光环；词缀双环描边更明显 |
| Boss | 裂空巨角（肩甲/三角/腰环）、星环邪核（双环/碎晶/内核）；攻击与冲撞时闪色 |
| 场景 | Canvas 程序地表贴图 + 指数雾 + 天穹；岩石堆叠 / 晶体簇升级 |
| 特效 | 投射物光晕拖尾、击杀八面体粒子、经验球光晕；Boss 弹同样强化 |
| UI | 选角卡 SVG 剪影、HUD / 升级卡阴影与光晕（CSS） |
| 贴图细化 | Canvas atlas：毛发/鳞片/羽纹；敌人裂纹；Boss 装甲板；地表第二层弱噪点 |
| Boss 残影 | 巨角冲撞拖尾残影；邪核攻击相位残像（上限 10，及时释放） |

碰撞半径与玩法数值尽量保持不变。详见 `CHANGELOG-art.md`。

## 安装与启动

```bash
cd starbeasts-survivor
npm install
npm run dev
```

浏览器打开终端提示的本地地址（默认 `http://localhost:5173`）即可游玩。

生产构建：

```bash
npm run build
npm run preview
```

## 精英词缀

精英怪必带 1 个词缀；虚空甲虫等中后期高强度怪有概率带词缀。脚下彩色描边 + 头顶小标区分。

| 词缀 | 效果 |
|------|------|
| 迅疾 | 移速 ×1.5 |
| 硬化 | 受伤 ×0.5，抗击退 |
| 再生 | 每秒回复约 4.5% 最大生命 |
| 爆裂 | 死亡时对附近玩家造成范围伤害 |
| 分裂 | 死亡分裂出 2 只较弱小怪（不再二次分裂） |
| 冰霜 | 接触使玩家短暂减速（约 1.6s，移速 ×0.55） |

击杀带词缀敌人时 HUD 会短暂提示「击破词缀 · xxx」。

## 刷怪避障

Spawner / 精英潮 / Boss 召唤小怪在落点检测障碍碰撞半径，最多重试约 14–16 次，必要时向外围偏移；仍失败则使用最后候选点（随后碰撞系统仍会推出重叠）。

## 地图障碍

每局开局随机散布约 14–19 个障碍（避开出生点约 5.5 单位）：

| 类型 | 碰撞 | 破坏 |
|------|------|------|
| 岩石（灰石几何） | 玩家 / 敌人 / Boss 不可穿模；阻挡敌我投射物 | 不可破坏；Boss 冲撞会抖动并溅粒子 |
| 晶体（青色八面体） | 同上 | 玩家投射物可打碎；Boss 冲撞直接撞碎（粒子 + 音效） |

## 操作说明

| 操作 | 说明 |
|------|------|
| WASD / 方向键 | 移动 |
| 触摸虚拟摇杆（左侧） | 移动端移动；与 WASD 并存，桌面不显示；升级/选角时隐藏 |
| 鼠标移动 | 略微影响角色朝向 |
| 自动 | 攻击最近敌人（优先锁定 Boss） |
| 升级弹窗 | 游戏暂停，三选一强化 |
| P / Esc | 暂停 / 继续（升级选择期间不切换，保持弹窗） |
| HUD 右上角 🔊 | 一键静音 / 取消静音 |
| 选角界面 | 声音开关、BGM 开关、音量滑条（存 localStorage） |
| Game Over | 可重开或返回选角；展示本局与本机最高纪录 |

## 起始角色

1. **焰心狐** — 火系弹道，伤害高  
2. **潮汐龟** — 水波环攻，坦度高  
3. **风刃隼** — 风刃射速高、移速高  

## 武器进化

每名起始角色的基础武器可进化 **2 次**（共 3 形态）。升级三选一可能出现「武器进化」史诗卡；若未选手动进化，到达 **7 / 14 级**会自动解锁下一形态。进化时 HUD 横幅提示并播放进化音效；形态用颜色 / 大小 / 环数 / 粒子区分。

| 角色 | Tier0 | Tier1 | Tier2 |
|------|-------|-------|-------|
| 焰心狐 | 火核弹 | 爆裂弹（溅射） | 连锁火球（弹跳 + 溅射） |
| 潮汐龟 | 水波环 | 双潮环 | 潮汐脉冲（周期冲击击退） |
| 风刃隼 | 风刃 | 多重风刃（额外扇形） | 穿透风暴（强穿透） |

## 词条与协同

升级池在原有属性强化外增加词条：**暴击、击退、冷却缩减、经验加成、护盾、溅射**。凑齐协同所需升级后即时发动，并在升级卡底部用小字提示可能的协同。

| 协同 | 所需 | 效果 |
|------|------|------|
| 疾锋 | 暴击晶核 + 迅击律动 | 暴击伤害 +0.35，攻击间隔再 -8% |
| 碎星裂变 | 碎星溅射 + 弹射弹道 | 溅射半径 +30%，穿透 +1 |
| 晶甲回响 | 星盾凝结 + 噬星回响 | 击杀回复护盾；吸血 +2% |

## 平衡手感

近期调过一版节奏：前 60 秒偏教学、首 Boss 可风筝、120 秒后加压；三角色差异（狐高伤脆 / 龟坦慢 / 隼机动）更清晰。升级伤害加成略收、生存选项权重提高。对局中按 **B** 可查看当前难度倍率。详见 `CHANGELOG-balance.md`。

## Boss / 事件波次

按存活时间触发（可叠加后续循环）：

| 时间 | 事件 |
|------|------|
| 60s | Boss **裂空巨角**（冲撞 + 召唤小怪） |
| 90s | **精英潮**（约 12 秒高密度刷怪） |
| 120s | Boss **星环邪核**（环形弹幕 + 召唤） |
| 150s | 精英潮 |
| 180s+ | 每 30 秒交替：强化 Boss / 精英潮 |

- HUD 会显示「Boss 来袭」或「精英潮」提示，并播放警告音效  
- Boss 在场时屏幕顶部显示 **名称 + 大血条**，随伤害更新，击败后隐藏  
- 击败 Boss：掉落大量经验球 + 约 8 秒短暂移速/射速强化  

## 体验打磨

- **Boss 屏幕血条**：在场时顶部名称 + 大血条
- **出生保护**：开局约 3 秒无敌，HUD 提示
- **飘字**：玩家受伤红色数字；弹道/脉冲暴击金色「暴击 n」
- **暂停**：P / Esc；与升级弹窗暂停一致（升级中不响应切换）
- **拾取音节流**：经验球连拾时音效最短间隔约 55ms

  data/        # 角色、敌人、Boss、升级、词缀、武器形态

## 已知限制

- 敌人 AI 主要为追踪玩家；Boss 有冲撞 / 弹幕 / 召唤模式
- 障碍为圆形近似碰撞，复杂形状未单独建模
- 刷怪已避障重试，极端密集障碍下仍可能落在次优点
- Boss 敌对弹幕未做对象池（数量有限，局内清理）
- 无账号 / 在线排行
